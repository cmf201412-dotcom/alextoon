# AlexToon Subidas

**AlexToon Subidas** es una herramienta privada del canal de YouTube **AlexToon** (videos animados de supervivencia, ciencia y curiosidades en español).

La usa únicamente el propio creador del canal, desde su computador, para subir sus videos ya terminados a su canal de YouTube, ponerles título, descripción, etiquetas y miniatura, y programar la hora de publicación. Usa la API de YouTube Data (YouTube API Services).

No es una aplicación pública: no tiene otros usuarios, no accede a cuentas de terceros y no vende ni comparte datos.
